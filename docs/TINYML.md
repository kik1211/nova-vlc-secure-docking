# N.O.V.A. TinyML Model & Edge Impulse Integration

## 1. Overview & Machine Learning Pipeline

Subsystem 1 uses an on-device neural network to classify optical key frequencies directly on the ESP32-S3 microcontroller. The model is trained and deployed using Edge Impulse (Project: `NOVA_Secure_Lock`).

```text
100 Raw ADC Samples (1.000 s @ 100.0 Hz)
            │
            ▼
┌───────────────────────────────────────────┐
│ Edge Impulse Spectral Analysis DSP Block  │  16-point FFT & spectral power estimation
│ (Generates 13 spectral features)          │
└─────────────────────┬─────────────────────┘
            │
            ▼
┌───────────────────────────────────────────┐
│ Fully Connected Neural Network (Dense MLP)│  13 -> 20 (ReLU) -> 10 (ReLU) -> 4 (Softmax)
│ (534 float32 parameters / 2.1 KB)         │
└─────────────────────┬─────────────────────┘
            │
            ▼
┌───────────────────────────────────────────┐
│ Output Probabilities (4 Classes)          │  [freq_10hz, freq_20hz, freq_30hz, noise]
└─────────────────────┬─────────────────────┘
            │
            ▼
┌───────────────────────────────────────────┐
│ Confidence Gate                           │  Require winning class confidence >= 0.85
└───────────────────────────────────────────┘
```

## 2. Model Architecture & Layer Breakdown

The compiled model is an EON-compiled feedforward neural network (`tflite_learn_957717_3_compiled.cpp`) operating on 13 features generated by the spectral analysis DSP block:

| Layer | Type | Dimensions / Shape | Activation | Parameters |
|:---|:---|:---|:---|:---:|
| **Input** | Feature Vector | $13\text{ features}$ | — | 0 |
| **Dense 1** | Fully Connected | $13 \rightarrow 20\text{ units}$ | ReLU | $260\text{ weights} + 20\text{ biases} = 280$ |
| **Dense 2** | Fully Connected | $20 \rightarrow 10\text{ units}$ | ReLU | $200\text{ weights} + 10\text{ biases} = 210$ |
| **Output** | Fully Connected | $10 \rightarrow 4\text{ units}$ | Softmax | $40\text{ weights} + 4\text{ biases} = 44$ |
| **Total** | | | | **534 parameters** |

* **Target Classes:**
  * `freq_10hz` — Guest Role optical key ($10.0\text{ Hz}$)
  * `freq_20hz` — Staff Role optical key ($20.0\text{ Hz}$)
  * `freq_30hz` — Admin Role optical key ($30.0\text{ Hz}$)
  * `noise` — Ambient light, DC saturation, or unmodulated flicker

## 3. Resource Footprint & Performance on ESP32-S3

* **Inference Latency:** $\approx 2.14\text{ ms}$ ($2,140\ \mu\text{s}$) total execution time (DSP feature extraction + neural network inference) on the 240 MHz Xtensa LX7 dual-core processor.
* **Flash Memory Footprint:** $\approx 2.1\text{ KB}$ for compiled model weights ($534 \times 4\text{ bytes} = 2,136\text{ bytes}$). Total compiled inferencing library footprint is $\approx 42.8\text{ KB}$ including CMSIS-NN and Edge Impulse runtime routines.
* **RAM Footprint:** $2,982\text{ bytes}$ tensor arena buffer allocated in internal SRAM.
* **Confidence Gating:** A minimum probability of $0.85$ ($85.0\%$) is required for the predicted class. Any output below $0.85$ triggers an `AUTH_REASON_ML_LOW_CONFIDENCE` veto in the state machine.

## 4. Firmware Integration API

The application layer accesses inference through the wrapper interface in [`subsystem1_secure_access/src/ml/classifier_wrapper.h`](../subsystem1_secure_access/src/ml/classifier_wrapper.h):

```cpp
#include "src/ml/classifier_wrapper.h"

// Initialize classifier and internal tensor buffers
bool ok = classifier_init();

// Execute inference on a 100-sample raw ADC buffer
ClassifierResult_t result;
bool success = classifier_run(sampleBuffer, 100, &result);

if (success && result.confidence >= 0.85f) {
    // result.label contains "freq_10hz", "freq_20hz", "freq_30hz", or "noise"
    // result.confidence contains the floating-point probability (0.0 to 1.0)
}
```
